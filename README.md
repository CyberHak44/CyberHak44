## What I work on

- **Regulatory crosswalks**: mapping UAE and GCC rules (CBUAE, UAE IA, UAE PDPL, NCA ECC-2:2024) to ISO/IEC 27001:2022 and NIST CSF 2.0, so one programme meets all of them.
- **Third-party and operational resilience risk**: supplier due diligence, critical operations mapping, exit planning.
- **OT and building systems risk**: AV, BMS and network systems in high-value properties. These are the connected devices most security teams overlook.
- **Incident case files**: public incidents read the same way each time: signal or noise, tell-tale signs, gaps, and what to change.
